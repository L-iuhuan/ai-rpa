# U8委外核销自动化工具 - 使用说明

自动完成用友U8"委外核销"界面的: 滚动列表 → 勾选未勾选的复选框 → 点击"核销" → 处理确认弹窗。

为防止一次勾太多导致U8卡顿, 默认**每批最多勾选 3 屏**(可在 config.json 里改 `max_screens`), 勾满一批核销一批, 剩余的再次运行即可继续。

---

## 一、今天第一次上手(按顺序做)

### 第0步: 确认依赖已装好(只需一次)

打开命令行(cmd 或 PowerShell), 执行:

```
cd /d E:\3-其他资料\工作文件\U8委外核销自动化
python -m pip install -r requirements.txt
```

(本机已装好, 跳过也行)

### 第1步: 试试识别(不动鼠标, 绝对安全)

把U8核销界面打开、显示出列表, 然后:

```
python u8_hexiao.py dry-run
```

它会截图识别当前屏幕的未勾选复选框, 把结果画红框存到 preview.png, 并打印坐标。**不会点击任何东西**。
看到"匹配到 N 个"就说明识别正常。

### 第2步: 只勾选、不核销(过渡期用法, 推荐今天先用这个)

```
python u8_hexiao.py select-only
```

- 3秒倒计时后开始, 自动滚动并勾选, **勾满3屏自动停**
- 停下后你自己检查一眼, 手动点"核销"、点"确定"
- 列表还有剩余? 等刷新稳定后, 再运行一次同样的命令, 它会从当前位置继续往下勾

### 第3步: 全自动(用顺手后再上)

先花1分钟校准两个按钮坐标(只需一次):

```
python u8_hexiao.py calibrate
```

校准过程(按提示把鼠标移到目标上, 回到命令行窗口按回车):

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1/5 | 鼠标放到某个**未勾选复选框**中心, 回车 | 会自动截新模板, 问是否启用时直接回车(用原来的)即可, 因为识别已验证正常 |
| 2/5 | 鼠标放到复选框列**左上角**, 回车 | 也可以直接抄默认值: 移到屏幕最左上附近 |
| 3/5 | 鼠标放到复选框列**右下角**, 回车 | 抄默认: 移到 (108, 1395) 附近 |
| 4/5 | 鼠标放到**核销按钮**上, 回车 | ★ 这是关键的一步 |
| 5/5 | 鼠标放到确认弹窗**确定按钮**上回车; 或输入 s 跳过 | 跳过则用"按回车键"方式处理弹窗(U8弹窗默认聚焦确定, 回车即可) |

校准完成后:

```
python u8_hexiao.py test-one    ← 先试一小批: 只勾当前屏+核销+确认
python u8_hexiao.py run         ← 正式用: 滚动勾满3屏+核销+确认
```

`run` 跑完一批会提示你: 列表还有剩余就再运行一次, 直到它打印"已到列表底部"。

## 二、日常使用速查

| 场景 | 命令 |
|---|---|
| 看识别是否正常(不动鼠标) | `python u8_hexiao.py dry-run` |
| 自动勾选, 手动核销 | `python u8_hexiao.py select-only` |
| 全自动一批(勾3屏+核销+确认) | `python u8_hexiao.py run` |
| 小批量试跑 | `python u8_hexiao.py test-one` |
| 重新校准按钮/模板 | `python u8_hexiao.py calibrate` |
| 自检算法(不动鼠标) | `python u8_hexiao.py selftest` |

建议工作节奏: 打开U8核销界面 → `run` → 等它报"本批完成" → 看一眼U8结果 → 列表没空就再 `run` → 循环到"已到列表底部"。

## 三、急停(务必记住)

- **鼠标猛甩到屏幕左上角** —— 立即中止
- 或在命令行窗口按 Ctrl+C
- 硬性保险: 总点击数达到 500 次自动停(config.json 的 `max_clicks_total`)

---

## 四、每批勾多少? (防卡顿设置)

config.json 里的 `max_screens` 控制:

```
"max_screens": 3      ← 每批最多勾3屏(默认)
```

- 还是卡: 改成 2 或 1
- 不卡想快点: 改成 5、10 都行
- 想一次勾完整个列表: 改成 999

相关参数:
```
"click_delay_ms": 200    每次勾选点击的间隔(毫秒), 卡可加大到300-400
"scroll_pause_ms": 400   每次滚动后等待界面刷新的时间
```

## 五、config.json 完整参数表

| 参数 | 默认值 | 说明 |
|---|---|---|
| window_title | 核销 | 启动时自动激活标题含此文字的窗口 |
| region | [0,50,108,1395] | 复选框列的识别区域 [左,上,右,下] |
| template | assets/checkbox_raw.png | 未勾选复选框模板图(来自Quicker, 已验证) |
| match_threshold | 0.85 | 识别阈值; 识别不到降到0.80, 误识别升到0.90 |
| click_delay_ms | 200 | 勾选点击间隔(毫秒) |
| scroll_clicks | 3 | 每次滚动的滚轮格数 |
| scroll_pause_ms | 400 | 滚动后等待刷新(毫秒) |
| **max_screens** | **3** | **每批最多勾几屏, 防卡顿的核心开关** |
| hexiao_button | null | 核销按钮坐标(calibrate 第4步采集) |
| confirm_strategy | enter | 弹窗处理: enter=按回车 / click=点确定按钮 |
| confirm_button | null | 确定按钮坐标(calibrate 第5步采集, 可为null) |
| confirm_enter_times | 3 | 回车策略下最多按几次回车(通常1次就够) |
| post_hexiao_wait_s | 1.5 | 点核销后等多久再处理弹窗(秒) |
| max_clicks_total | 500 | 总点击数安全上限 |
| endless_scroll_guard | 2 | 连续N次滚动画面无变化=到底了 |

改完 config.json 保存即可, 下次运行生效。

## 六、常见问题

**Q: dry-run 匹配 0 个?**
U8界面没打开/没显示列表行; 或界面主题缩放变了导致模板失效 → 运行 calibrate 第1步重新截模板(问是否启用时输入 y)。

**Q: 点击位置有偏移?**
高分屏缩放问题, 工具已内置DPI处理; 确保直接用 `python u8_hexiao.py ...` 运行, 不要套在别的终端里。

**Q: 核销后确认弹窗没被处理?**
用 calibrate 第5步采集"确定"按钮坐标(策略自动变为 click); 或确认 post_hexiao_wait_s 是否太短(U8反应慢就加大到 2~3)。

**Q: run 完一批后, 列表位置变了, 再 run 会重复勾吗?**
不会。已勾选的框不再是"未勾选"样式, 模板匹配不到, 会自动跳过并从当前位置继续。

**Q: 回车策略会不会误按到别的东西?**
confirm_enter_times 默认3次是兜底; 如果确认框一次回车就关, 改成 1 更稳妥。

**Q: 想中途停止?**
鼠标甩左上角急停, 或 Ctrl+C。停了之后已勾选的不受影响, 手动核销或重新运行都可以。
