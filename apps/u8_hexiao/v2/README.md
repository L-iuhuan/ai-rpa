# U8委外核销自动化 v2 — 使用说明

v2 = 规则引擎 + 元素识别(OCR) + 小界面。按采购类型和数量规则自动判定每一行：直接核销 / 修正后核销 / 跳过留人工。

## 安装(仅首次)

```
cd /d E:\3-其他资料\工作文件\U8委外核销自动化\v2
python -m pip install -r requirements_v2.txt
```

## 启动界面

```
python gui.py
```

## 第一次使用(按顺序)

1. **打开U8委外核销界面**(显示上下两个列表)
2. 界面顶部点 **[测试连接]** —— 应显示窗口尺寸;失败则核对窗口标题
3. **规则配置**: 把你们实际用的采购类型加进去, 分类选 A(按件数核对) 或 B(按数量核对)。
   - A类(如"封测编"): 上下件数比对, 一致且本次核销=未核销→直接核销; 一致但本次核销偏小→自动改成未核销数量再核销; 上件数<下件数→直接核销; 其余跳过
   - B类: 入库数量≤未核销数量→直接核销, 否则跳过
   - **没配置的类型一律跳过留人工**, 不会误核销
4. **[校准核销按钮]**: 点击后把鼠标放到U8的"核销"按钮上别动, 3秒后自动采样
5. **[保存配置]**
6. **[生成计划(dry-run)]**: 不动鼠标, 只截图识别并输出每行判定(看日志区), 检查识别和判定是否符合预期
7. 小批量试跑: 行数上限填 `2`, 点 **[开始执行]**, 到U8里人工核对这2行的核销结果
8. 没问题后清空行数上限, 正式运行

## 运行逻辑

逐行从上到下: 点击上表行(下表联动刷新) → OCR读上下两表数据 → 规则判定 → 执行(勾选+修正+核销+确认) → 下一行; 当前屏处理完自动滚动翻页继续, 直到列表底部。

## 急停

- **鼠标猛甩到屏幕左上角**(随时有效)
- 界面 **[停止]** 按钮
- 安全阀: 总点击数达上限自动停(默认800)

## CLI(可选)

```
python main.py selftest    离线自检(规则+视觉fixture回归, 不动鼠标)
python main.py plan        判定计划(不动鼠标)
python main.py run --rows 3   只处理前3行
```

## 常见问题

| 问题 | 处理 |
|---|---|
| 识别不到表头 | 确认U8窗口完整可见(未被遮挡); 界面字体缩放若调整过, 重启U8恢复默认 |
| 某行判定SKIP但你觉得该核 | 查日志原因: 多为"下表联动多行"或"件数/数量读不到", 属于规则约定留人工的场景 |
| MODIFY改数没生效 | 调大 pacing.row_settle_ms(config_v2.json, 默认500→800) |
| 确认弹窗没处理掉 | 界面里调大"确认回车次数"(默认2) |
| 想换回v1批量勾选 | 用上级目录的 u8_hexiao.py(仍然可用) |

## 目录结构

```
v2/
├─ gui.py              界面入口
├─ main.py             CLI入口
├─ config_v2.json      配置(界面里保存)
├─ core/               规则引擎+视觉+执行(勿手改)
├─ tests/              测试基准(规则单测+OCR实验+fixture截图)
├─ docs/方案规则文档.md  完整方案、规则、里程碑记录
├─ DEVELOPMENT_LOG.md  开发记录
└─ logs/               运行日志(每次运行落盘)
```

## 与 v1 的关系

- v1(u8_hexiao.py): 批量盲勾, 适合"全部都要核"的 B 类场景, 保留可用
- v2: 逐行规则判定, A类/需修正/需甄别的场景用它; 两者可配合
